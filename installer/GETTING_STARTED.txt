Cantonese IME

Windows 10/11, native x64 applications

Press Windows + Space and choose Cantonese IME. Type plain Yale or Jyutping
letters. For example, fogeui finds 火炬. Press a candidate's number or Space
to select it. The compact candidate window shows numbered choices.
To type an English word, press Shift+Space (or Space when no candidate
matches) to enter the letters with a space; Enter enters them without one.
Common English words, and words you have entered this way, appear as a
candidate themselves.

Cantonese IME appears under Chinese (Traditional, Hong Kong SAR). Setup adds
this keyboard input source for your account and preserves your English
keyboard, other languages, Windows display language, and default override.
The old English-slot Cantonese entry is removed after the Hong Kong source
is verified. If you explicitly made that old entry your default, it is kept.
No Windows language pack is downloaded by this installer.

The taskbar button shows 粵 for Cantonese and 英 for direct English input.
Click that button to change modes. Existing applications may need to be
closed and reopened after an upgrade before the new icon appears.

The candidate window uses the bundled LXGW WenKai TC font. No separate
Windows font installation is needed. Right-click the candidate panel or the
taskbar's Cantonese/English button to choose Dark, Light or System colors
and panel opacity. These choices are saved separately for each application.
The default is Dark at 95% opacity; choose 100% for an opaque panel. Windows
High Contrast uses system colors and full opacity automatically. If an app
draws its own candidate list, that app controls the list's appearance.
Saved appearance choices are kept at:
  %LOCALAPPDATA%\CantoneseIME\appearance.ini
To use another installed font or size, add lines like these under [global]
in that file (font accepts English or Chinese names; size 10-48, default 20):
  font=Microsoft JhengHei
  font_size=24

Candidate preferences and phrases are learned locally on this computer.
Choosing ng -> 唔 also helps longer combinations such as ngho -> 唔好 and
nghaigam -> 唔係咁. Choosing a whole phrase learns that phrase separately,
so a short input and a longer input can keep different preferred choices.
The engine works offline. Personal learning is stored separately at:
  %LOCALAPPDATA%\CantoneseIME\learning.json
Upgrades and uninstall keep that file.
They also keep your saved appearance choices.

Start menu > Cantonese IME > Cantonese IME Settings (or right-click the
candidate panel > Custom phrases, spellings and font...) edits your own
phrases, spellings and the candidate font and size without opening files.
Its 查拼音 tab shows a character's or word's readings and the spellings you
can already type, so you know what to map a custom spelling to.
Its 字型同聯想 tab can turn on experimental next-word suggestions learned
only from your own typing (off by default; digits 1-9 choose, Escape closes).
Close it before upgrading.

To edit phrases or spellings by hand, use this UTF-8 text file:
  %LOCALAPPDATA%\CantoneseIME\custom.txt
One entry per line; lines starting with # are comments. For example:
  hh 曈曈        typing hh offers 曈曈 first
  moon = mun     moon is read as the syllable mun, so it finds 門
Changes apply on the next keystroke. Upgrades and uninstall keep the file.

Start menu > Cantonese IME > Enable Cantonese IME starts the engine and
enables the keyboard for your account. It also arranges startup at sign-in.
Start menu > Cantonese IME > Stop Cantonese IME stops the engine.
Use Windows Settings > Apps > Installed apps > Cantonese IME to uninstall.
Close applications using this keyboard and sign out other users first.
Windows may request a restart when files are still in use.

This installer includes a private Python runtime. Python, a compiler,
developer tools and an Internet connection are not needed on the target PC.
Run Setup normally and approve its Windows administrator prompt. Do not
start Setup with "Run as administrator": user activation needs the original
ordinary user account. If that happened, use the Enable shortcut afterward.

The package is unsigned. Windows may show an unknown publisher or
SmartScreen prompt. Check the supplied SHA256SUMS.txt before distributing.
This release does not include a code-signing certificate.

Supported scope: Windows 10/11 x64, native 64-bit desktop text controls.
32-bit applications, ARM64 Windows and secure/password fields are outside
this release's supported scope. Dictionary reachability was mechanically
checked; generated readings and ranking can still need language corrections.
